# 修行体系

## 零、主角天赋：心悸
- **本质**：感知"注视"。被杀意、神目、天眼盯上时，心口会骤然发紧、绞痛。来源是傩血加庚申夜出生（傩人世代能感知神的目光）。
- **成长**：
  1. 心悸：只知道"有危险"，不知道来自哪里（开局）
  2. 见尸：纸人挡刀那一夜开眼，能看见三尸（卷一第一个高潮）
  3. 辨向：能分辨注视来自人、神还是天（卷一后段）
  4. 预刻：能提前一息感知三尸出窍的瞬间，这是斩尸下刀的关键（卷一高潮）
  5. 共感：通过半张傩面感知阿蘅的危险（卷三之后，感情线的纽带）
- **弱点**：注视太多、太强时会被淹没。庚申夜天眼俯视全城时，他会心悸到呕血。
- **太岁疙瘩**（卷一第 26 章起）：主角借过一次煞，心口偏左长了一块铜钱大的太岁疙瘩，跟心长在一起，割不掉。它压在"会疼的地方"上，**心悸从此钝了一层**，"像隔着一块肉，听人敲门"。主角想吃生肉时它会长。借煞期间心悸完全失灵。

## 零之二、保命身法：听风（孟瞎子所授）
- **来源**：摸骨相门的瞎子常在江湖走，必须"不挨打"。孟瞎子用"念信"换来的条件，教主角基本的保命武术。
- **原则**："瞎子不打人，瞎子只是不让人打着。"不往后退，后退是墙还是河都不知道。
- **三式**：
  1. **听**：用耳朵、皮肉、骨头去听风声、脚步声、呼吸，吸气是蓄力，呼气是出拳。
  2. **挪**：心口告诉你"哪儿"，就**斜着往前挪半步**，挪进对方胳膊肘里头，让他的拳头没地方落。只挪半步，挪多了后脚跟不上。
  3. **绊**：挪进去以后，脚勾对方脚后跟，肩膀靠对方胸口，人就倒；**然后跑**，十丈够活命。
- **与心悸配合**：心悸负责"有"和"哪儿"（训练后能分辨方向），听风负责"怎么动"。主角踮脚走路的习惯（脚后跟不着地）被孟瞎子看作转身快的天赋。
- **借煞时**：心悸被太岁堵死，全靠听风作战；煞力加持下，"绊"能把人掀飞。
- **后续**：作为打斗戏的基础，后面可以继续扩展（例如卷二向萨满、赶尸人等学习其他身法）。

## 一、主角三法

### 1. 斩尸（对天）
| 境界 | 内容 | 获得 | 卷 |
|---|---|---|---|
| 见尸 | 能看见自己和他人体内的三尸 | 看穿谁正在被天监视；看人"罪念"的轻重 | 一 |
| 斩上尸·彭倨（头） | 斩去上尸 | 神清：抵抗精神污染、看破幻术，天无法读取你的念头 | 一 |
| 斩中尸·彭质（腹） | 斩去中尸 | 心定：情绪不再被收割，不惧香火侵蚀，五脏坚如铁石 | 二 |
| 斩下尸·彭矫（足） | 斩去下尸 | 形解：从《司命簿》上除名，寿限解除，天无法定位你 | 四 |
| 三尸俱斩 | 无籍之人 | 天的规则对你失效，你成了天眼中的"漏洞" | 四 |

- 斩尸需要在庚申夜、三尸出窍的那一瞬下刀，主角靠心悸的"预刻"抓住这一瞬。
- 斩下的三尸不会死。它们会被"纸性"的东西困住，主角把它们封进自己的武器，成为器灵。

### 2. 纸扎（欺天）
主角不是从小学的手艺，而是在卷二从扎纸行会**偷学、换学**来的，再加上三娘留下的笔记一点点补全。
| 层次 | 内容 |
|---|---|
| 扎形 | 扎出纸人、纸马、纸屋 |
| 点睛 | 让纸人能动（禁忌：点睛会招来地的碎片） |
| 封尸 | 把三尸困进纸或有"纸性"的器物 |
| 替身 | 纸人写上某人生辰，可替此人受劫，三尸告状也会告到纸人头上 |
| 欺天 | 让封尸器物向天发送假情报（全书高潮手段的雏形） |

### 3. 傩面（借地）
| 层次 | 内容 |
|---|---|
| 请神 | 戴面请来面具对应的神力（开山＝怪力，判官＝审魂，土地＝遁地……） |
| 借面 | 不戴面也能借力，面具纹路浮现在脸上 |
| 共面 | 两人各持半张同源面具，合力请神（主角与阿蘅） |
| 刻己面 | 为自己刻一张人面傩，以人身成神，不借地的力（终极境界） |

## 三、代价机制（写作时必须可见）
- **天眼**：每次斩尸、欺天被识破、使用越权的手段，天的注视都会加深。表现依次为：庚申夜星光偏斜照向你 → 周围人梦见同一只眼睛 → 晴天落雷 → 星官下降。
- **面蚀**：每次戴傩面，面具都会往脸上长一点。表现依次为：皮肤木纹化 → 忘掉某段记忆 → 听见地底的呼唤 → 别人认不出你的脸。
- 天眼和面蚀同时太高会被两头撕扯，这是中后期的主要危机。

## 四、其他派系体系
- **昊天道·箓法**：受箓分级（都功箓 → 盟威箓 → 上清箓 → 天箓），越高雷法越强，三尸也被"敕封"，成为天的官。高阶道士会逐渐变成天的傀儡（星官）。
- **无面娘娘教·香火神**：供奉得越虔诚，能借的神力越强；代价是失去面目、最终化为神像。
- **九流秘术**：赶尸（控尸行路）、走阴（魂入阴间探路）、哭丧（以哭声安魂或惊魂）、刻碑（碑文定魂、镇物）、吹打（乐声驱邪）。
- **空山寺·无我**：无我则三尸无主可告，天看不见；但无法主动攻击，一旦起嗔念，"我"就会回来。
- **钦天监·观星术**：用浑天仪与星图推算天的运转，能预测天罚、短时间遮蔽星宿，接近"技术"。

## 五、旁门左道（小门小派）

> 定位：散落各地的小门小派，不属于天、地两大体系的正统。它们用来推动支线剧情，或者让主角偷学、交易、借用，补充部分能力。主角每接触一门，都应该从中多认识一点"世界本质"。
> 原则：每一门都有**明确的能力、明确的代价**，并且能说清它和天、地、人三方的关系。

### 1. 黑水神鼓（萨满·跳神）
- **来历**：关外黑水河一带的萨满，汉人叫"跳大神"，入关后散在北方各州县，走村串户治病驱邪。
- **组织**：两人一组。"大神"负责请神上身、起舞；"二神"负责敲神鼓、摇腰铃、唱神调。没有固定山门，师徒口传。
- **所拜**："山仙"，也就是老林子里活了千百年的东西，非天非地。萨满说："天管不着林子，地也啃不动老树根。"
- **能力**：
  - **百草燎**：把采来的草药扎成束点燃，用药烟熏遍全身，能止血、退烧、驱寒。
  - **神鼓调**：二神击鼓唱调，大神跳"踩罡步"，鼓点一响，伤者的魂就"稳"下来，昏迷可醒，惊魂可回。
  - **请山仙**：大神请山仙上身，以手抚伤，断骨能续，伤口能收，是全书最实在的**恢复类**手段。
- **代价**："借山还山"。请一次山仙，就欠那片林子一笔"山债"，往后要年年供奉，那片林子里一棵树都不许伐。欠得多了，人会"长根"：离开那片山越远，脚底越疼，最后再也走不出林子，成了"山里的人"。
- **与主角**：卷二起可能遇到行走江湖的萨满；主角重伤时可以靠跳神保命，代价是欠下山债，形成一条长线牵绊。
- **世界观价值**：说明天地之外还有"野"的、更古老的东西。

### 2. 天外教（泰西圣咏）
- **来历**：明末风格的泰西传教士，坐海船来，大胤人叫"番僧""洋和尚"，教士自称"司铎"。有几个司铎在钦天监修历、造浑天仪。
- **教义**："汝等所拜之天，非天也，乃穹也。真主在穹之外。"他们认为昊天不过是一层"穹顶"，真正的神在它外面。昊天道视之为邪说，朝廷因为用得着他们修历，所以容忍。
- **能力**：
  - **圣咏**：用泰西古语吟唱经文。圣咏所及之处，幻象破除，比如娘娘庙里供桌上"最想要的东西"会露出本来面目；心神被稳住，精神污染被暂时压下。
  - **圣水**：在清水里念经而成。水本来就能切断与天的联系，圣水更强，泼在额头上可以短时间让天"看漏"。
  - **告解**：对司铎说出自己的罪，可以暂时让三尸"无账可念"（司铎替你背了账）。
- **代价**：圣咏是一种越过天的祈祷，**唱得越响，天的注视就越近**，天会嫉妒。老司铎很多都疯了，说自己在夜里"听见穹顶外面的回声"，那回声很冷，比天还大，不知道是不是他们的主。
- **与主角**：可以作为破幻、净心的外援，例如主角学会一段圣咏，用来对付地的幻象。卷五钦天监中是重要伏笔：天地之外还有什么？
- **世界观价值**：给"天之外"留下第一道门缝，呼应卷五的星图揭示。

### 3. 血食坛（血教·借煞）
- **来历**："血食"本是古语，指受牲畜祭祀。血食坛是流窜在军营、屠行、刑场附近的邪门，坛主叫"血食郎"。信徒多是屠户、刽子手、兵痞、亡命徒。
- **所拜**："太岁"。古人说"太岁头上动土"，太岁是长在地底的一团活肉，掘地时偶尔会挖出来。血食坛把它养在大瓮里，叫"坛子"。
- **能力**：
  - **血食**：用牲畜的内脏、心头血，乃至无主的尸首去喂坛子里的太岁，太岁就会长大。
  - **借煞**：割一小片太岁含在舌下，或者把坛里的汁水抹在心口，便能"借煞"。在一炷香的时间里力大无穷，不知疼痛，刀砍不退，眼睛发红，是全书最直接的**暴走类**手段。
- **代价**：太岁会在你身体里"扎根"。借一次，就想吃一次生肉；借多了，体温越来越高，身上长出一块块软肉疙瘩；借到最后，人就"肉化"，自己变成一坛新的太岁。
- **与主角**：属于诱惑型力量。主角可能在绝境中借一次煞，并为此付出代价（身上留下一块太岁疙瘩，作为长期隐患）。也可能作为反派手下的打手体系。
- **世界观价值**：**地不止一张嘴**。无面娘娘吃人的"脸"（身份），太岁吃人的"肉"（身体）。由此可以推断地底那个存在有很多张嘴，是卷三揭示的铺垫。
- **写作尺度**：祭祀过程一笔带过，只写气味、瓮、事后的痕迹，不做解剖式描写。

### 4. 草鬼婆（蛊）
- **来历**：西南苗疆的养蛊人，多为女子，汉人叫"草鬼婆"，靠近巫咸山一带。
- **能力**：**噬尸蛊**专吃人体内的三尸，算是"斩尸"之外的另一条路。被它吃掉三尸的人，天也看不见。
- **代价**：三尸吃完以后，蛊还会饿。养蛊人一辈子都得喂它，喂不上，它就开始吃宿主自己的"念头"，人会越来越呆、越来越空。
- **与主角**：卷三可以出场，作为斩尸路线的对照：别人用蛊吃，你用刀斩，哪个更像人？

### 5. 摸骨相门（瞎子算命）
- **来历**：街头算命的瞎子大多是江湖骗子，但其中有一脉真传，叫"摸骨相门"。
- **能力**：人出生时，南斗星君会把生辰八字和寿数"刻"在人的骨头上。只有瞎子摸得出来，他们说："眼睛看得见天，手就摸不到骨。"他们能摸出一个人还剩多少寿数、名字在不在簿子上。
- **代价**：必须是瞎子。半瞎的摸不准，复明的立刻失传。
- **与主角**：卷一青崖县城隍庙的**孟瞎子**（第一章提到的"说你命里有贵人"的那个算命瞎子）就是这一脉。他能摸出主角的骨头"是白的，没刻字"，是主角了解"无籍"的一个信息源。

### 6. 扶乩鸾堂
- **来历**：民间扶乩的乩坛，两人扶着桃木笔在沙盘上写字，号称请仙降笔。
- **能力**：确实能"请"到东西写字，问什么答什么。
- **代价**：谁也不知道请来的是什么。有时是游荡的三尸，有时是箓神在串话，有时是地底的东西在冒充。答案半真半假，问得越深，乩笔越像是在"反过来问你"。
- **与主角**：可作为危险的情报来源，适合悬疑支线。
